# Инструкция для Claude по этому репозиторию

Читается первой в начале сессии. Источник правды — репозиторий, а не память
о прошлом чате.

## Что это

**Кликабельный прототип** сайта туроператора IZI TOUR (izi.tours): чартерные
программы из Минеральных Вод, Краснодара и Саранска в Турцию, Египет и Китай.
Сделан для защиты концепции перед заказчиком — это **не рабочий сайт**.

Опубликован на GitHub Pages. Владелец — Алексей; он не программист,
инструкции давать пошагово.

## Устройство

Статика без сборки: HTML + CSS + JS, ни фреймворков, ни npm.

```
index.html            основная страница
agentam.html          агентства (вход-заглушка)
assets/css/site.css   все стили; тема — переменные в :root
assets/js/site.js     ДАННЫЕ и логика
assets/img/           иллюстрации WebP
DATA-REVISION.md      ревизия выдуманных данных — читать до правок контента
.nojekyll             обязателен для Pages
```

Все данные собраны одним блоком в начале `site.js` под заголовком
«ДАННЫЕ САЙТА», с оглавлением: `DATA` (вылеты и цены), `RESORTS_DATA`,
`FLEET` (компоновки салонов), `PROG` (расписание сезона), `SOON`
(ближайшие вылеты), `ADDONS`, `PAX_K`, `EB` (раннее бронирование),
`CLUB`, `BUD`, `FUNNEL` (девять шагов воронки), `IMAGES`.
**Правка контента не требует трогать вёрстку.**

Общие правила статических сайтов — в скиле `static-site-github-pages`.

## Что важно помнить

- **Это прототип, и он обязан выглядеть честно.** В `DATA-REVISION.md` данные
  разложены на три стопки: 🔵 из системы, 🟡 подтверждает заказчик,
  🔴 убрать или переделать. Красную стопку не «докрашивать» — там вещи вроде
  зачёркнутой цены, которой никогда не было, и придуманного «осталось 4 места».
  Это не стилистика, а закон о рекламе и доверие. **Новых выдуманных цен,
  остатков, отзывов и рейтингов не добавлять**; если для демонстрации нужно
  число — оно идёт в `DATA-REVISION.md` той же строкой.
- Тема — переменными в `:root`; класс `.dk` возвращает тёмные значения внутри
  «кадров» (первый экран, сцена курорта, маршрут, схема салона, подвал).
  Декоративные оттенки внутри картинных блоков намеренно жёсткие.
- Картинки — из объекта `IMAGES`, ключ = имя файла (`bodrum_sea` →
  `assets/img/bodrum_sea.webp`). Нет файла — интерфейс тихо откатывается
  на общий макет курорта. Не заменять этот механизм на прямые пути.
- Нижняя панель `#mbar` — единственный постоянный элемент поверх контента;
  когда она выехала, на `body` появляется класс `barup`, и нижние кнопки
  поднимаются. Ломать эту связку нельзя, иначе элементы перекроются.
- Посадочная страница `view-lp` собирается функцией `lpRender()` из тех же
  данных — отдельной копии текстов нет и заводить её не надо.
- Иллюстрации сейчас с водяным знаком Kling — до публикации нужен экспорт
  по платной лицензии.

## Проверка и публикация

Локально `python3 -m http.server 8080`, а не двойным кликом. Смотреть на двух
ширинах — сайт рассчитан прежде всего на телефон. Публикация — коммит и пуш
в `main`; сообщение коммита описывает изменение по сути.

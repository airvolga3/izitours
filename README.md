# IZI TOUR — прототип нового сайта

Концепт-прототип сайта туроператора IZI TOUR (izi.tours): чартерные программы
из Минеральных Вод, Краснодара и Саранска в Турцию, Египет и Китай.

Это **не рабочий сайт**, а кликабельный прототип для защиты концепции.
Данные в нём демонстрационные (см. раздел «Что нужно заменить»).

## Как посмотреть

Файлы статические, сборка не нужна. Достаточно локального сервера:

```bash
cd izi-tour
python3 -m http.server 8080
# открыть http://localhost:8080
```

Открывать `index.html` двойным щелчком тоже можно, но часть браузеров
ограничивает работу с локальными файлами — сервер надёжнее.

## Структура

```
index.html              разметка страницы
assets/
  css/site.css          все стили, тема на CSS-переменных
  js/site.js            данные, логика, схемы салонов
  img/                  иллюстрации в формате WebP
```

**Тема** задаётся переменными в начале `site.css` (блок `:root`).
Светлый вариант собирается подменой полутора десятков значений —
переписывать стили не нужно. Класс `.dk` возвращает тёмные значения
внутри «кадров» (первый экран, сцена курорта, маршрут, схема салона, подвал).

**Картинки** подключаются из объекта `IMAGES` в начале `site.js`.
Имена файлов совпадают с ключами: `bodrum_sea` → `assets/img/bodrum_sea.webp`.
Если файла нет, ключ остаётся пустым и интерфейс тихо откатывается
на общий макет курорта — ничего не ломается.

**Курорты** описаны в `RESORTS_DATA`, вылеты и цены — в `DATA`,
компоновки салонов — в `FLEET`.

## Что нужно заменить перед публикацией

| Что | Сейчас | Откуда брать |
|---|---|---|
| Цены и даты вылетов | демонстрационные | система бронирования / Tourvisor |
| «Осталось N мест» | придуманные числа | реальный остаток блока мест |
| Рейтинги и число отзывов | придуманные | подтверждение заказчика или убрать |
| Отзывы | вымышленные | реальные, с согласия авторов |
| Фото отелей | переиспользуют макеты курортов | фото отельеров |
| Компоновки салонов | типовые схемы | карты мест перевозчика |
| Телефон, РТО, реквизиты | с сайта izi.tours на 28.08.2026 | сверить |
| Логотип | вектор, обведённый с растра 320×175 | исходник .ai/.eps от дизайнера |
| Иллюстрации | сгенерированы в Kling, с водяным знаком | экспорт без знака по платной лицензии |

## Чего ещё нет

- Горы Аватара: вкладки «Города» и «Вечер»
- Мобильный первый экран: нужен вертикальный кадр 3:4
- Салоны изнутри для всех трёх типов ВС

## Технические заметки

- Одна страница, без сборки и зависимостей. Внешне подключается только
  Google Fonts (Onest + Playfair Display).
- Проверено на ширинах 360–1440 px, горизонтального переполнения нет.
- Учитывается системная настройка «уменьшить движение»: анимации отключаются.
- Хостинг для боевой версии должен быть в РФ — 152-ФЗ и доступность.
